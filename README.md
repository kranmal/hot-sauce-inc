# Hot Sauce Inc

A modern, single-file hot sauce storefront inspired by Sauce Demo. Pure HTML, CSS and JavaScript, no build step.

- Login, product grid with sorting, product detail, cart and a 3-step checkout
- SVG bottle illustrations with a custom "HOT SAUCE INC" logo
- Light/dark theme toggle (remembers your choice)

**Demo logins:** `standard_user` or `locked_out_user`, password `hot_sauce`.

## Run locally

```bash
python3 -m http.server 8790
```

Then open http://localhost:8790
